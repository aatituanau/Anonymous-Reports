# Generador de Denuncias UCE 🏛️

Una herramienta web frontend, rápida y anónima para generar documentos de denuncia formales bajo el Código de Ética Universitaria.

## 🚀 Características
- **Privacidad Total:** Sin bases de datos ni backend. Todos los datos se procesan localmente en el navegador del usuario para garantizar el anonimato.
- **Vista Previa en Tiempo Real:** Visualiza cómo queda el documento oficial mientras llenas el formulario.
- **Generación Directa:** Exporta al instante un PDF con formato oficial (incluyendo los sellos institucionales correspondientes) usando `html2pdf.js`.
